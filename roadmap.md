# StudentBIZ Nigeria Project Roadmap

This document outlines the five phases of development for the StudentBIZ Nigeria platform.

## Phase 1: Project Genesis & Digital Identity
- [x] **Baseline Architecture**: Vite, React, Tailwind CSS, and Supabase integration.
- [x] **Unified Auth Protocol**: Role-based registration (Student vs. Investor) with school/university mapping.
- [x] **Dashboard Baseline**: Initial layouts for Entrepreneur and Investor roles.
- [x] **Security**: Protected routing and global state management (`useAuth`).

## Phase 2: The Trust Protocol (KYC & Business Registration) [COMPLETED]
- [x] **Advanced KYC**: Implementing 11-digit BVN/NIN verification and document upload systems.
- [x] **Vibe Profile**: Standardizing the "My Vibe" profile across all dashboards with university details and trust badges.
- [x] **Venture Onboarding**: Implementing the business proposal submission flow for student entrepreneurs.


## Phase 3: Marketplace Discovery & Peer Check-in
- [ ] **Investor Marketplace**: High-fidelity discovery engine for Alumni/Community investors.
- [ ] **Advanced Filtering**: Searching by school, category, ROI, and risk level.
- [ ] **Pitch Deck Interactive**: Deep-dive views with founder narratives and project milestones.

## Phase 4: Investment Lifecycle & Financial Analytics
- [ ] **ROI Tracking**: Real-time performance metrics and charts for investor portfolios.
- [ ] **Funding Logic**: Secure investment/escrow system and automated repayment tracking.
- [ ] **Credit Scoring**: AI-driven algorithm for venture quality and community trust assessment.

## Phase 5: Ecosystem Expansion & Launch
- [ ] **University Portals**: Specialized views for school authorities to manage their ecosystems.
- [ ] **Public Launch**: Final security audits, payment gateway integration, and production deployment.
- [ ] **Scaling**: Expanding beyond initial schools to a national level.
